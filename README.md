# COA Duplicate Company Configuration PRO

**Odoo Module** | Versions: 17.0, 18.0, 19.0 | License: OPL-1

## Description
Seamlessly duplicate Chart of Accounts, Taxes, Journals, and Warehouses across companies in a multi-company Odoo environment.

## Author
**Community of accountants (COA-Egypt)**
- Website: https://www.coa-egy.com

## Installation
1. Download and place in your Odoo addons directory
2. Update the apps list
3. Install `coa_company_duplicator`
